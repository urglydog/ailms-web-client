# Tính năng frontend thêm trong phiên UI (26–28/11/2026)

## Đa ngôn ngữ (vi/en/zh/ja)
- **Khu admin** (đã nằm trong `develop`): toàn bộ 21 route đã dịch. Ngoài ra:
  - 12 bảng có tiêu đề dính khi cuộn (cao tối đa 70vh);
  - bảng lỗi tải thì có nút thử lại;
  - chú thích biểu đồ đủ tương phản.
- **Phần còn lại** (`e79b058`, `0434441`, `b6679d2`, `65059c0`, `3894983`, `960ed24`): khoảng 170 file, hơn 2.000 khóa dịch.
  - Kênh giảng viên: học liệu, thu nhập, onboarding, sửa khóa, giao tiếp.
  - Các trang: thi, khiếu nại, thanh toán, pháp lý (8 trang, dùng `t.rich`), hồ sơ, live, 404.
  - Component dùng chung: player, gia sư AI, Course Discovery, Hỏi đáp, header, kế hoạch học, `components/ui`.
  - lib/hooks: lỗi API, toast, schema cài đặt admin.
- **Công cụ hỗ trợ:**
  - `lib/i18n/translate.ts`: hàm `tr()` để dịch ngoài React;
  - `lib/languageName.ts`: tên ngôn ngữ theo `Intl.DisplayNames`;
  - `lib/dateFnsLocale.ts`: locale cho date-fns.
- `<html lang>` đổi theo ngôn ngữ đang chọn.
- Cố ý giữ tiếng Việt:
  - dữ liệu từ DB (tên khóa học, danh mục, banner bảo trì);
  - ký hiệu "đ";
  - giá trị gửi lên API;
  - tiêu đề tab do server tạo, vì ngôn ngữ chỉ được chọn ở phía trình duyệt.
